# SCARM2
## Simple Computer Aided Railway Modeller

This repository is a test of the usefulness of keeping modeling history using SCARM2 in GitHub. The files have the .scarm extension. The RAW displays EDATA and is not human readable. The SCARM2 software updates the backup file each time a layout is saved with the same name. In essence, it is possible to restore to the layout prior to the current save.
